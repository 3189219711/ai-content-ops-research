# 账号分类复刻工作流

---

## 流程总览

基于抖音多品类内容（舞蹈，搞笑段子），来源可为「大 V 主页」或「热门视频」二选一，复刻为自有微信小程序分发的创意娱乐内容。

- **定位**：内容侧以「高颜值出镜 + 角色化表演 + 情绪共鸣」建立价值锚点；点击侧由封面承接——以「主体形象 + 文案钩子」双因子驱动点击转化（详见下方封面策略）。
- **封面策略**：基础规则——数字人 / 角色形象为主体（占画面 70% 以上），叠加吸睛标题 / 钩子文案，做成「形象 + 文案」双钩子，而非单一摆张脸；标题 ≤10 字、压画面下方 1/3。在此基础上，通用封面玩法（不挑品类，可组合）：
  - **① 高光定格**：选视频里最炸 / 最反差 / 最表情包的一帧做封面，而非随便一帧
  - **② 主体突出**：数字人 / 角色占画面 70%+，第一眼看清「谁在演」
  - **③ 标题钩子**：≤10 字短句压下方 1/3，用好奇 / 悬念 / 共鸣驱动点击（如「3 秒变装，别眨眼」「前 3 秒我笑了」）
  - **⑥ 情绪外化**：放大表情 / 动作瞬间，让封面自带情绪，不用看文字就懂
  - **⑦ 热点借势**：叠加节日 / 热词 / 时效元素，给内容一个时间锚点蹭流量
- **核心机制**：一套复刻流程，通过多类型数字人演绎，产出多条内容线；品类随业务需要扩展（当前支持复刻：舞蹈类视频、搞笑段子视频）

---

## 第一步：选类型 + 填来源

**先选类型**：确定本次要复刻的内容品类（舞蹈，搞笑段子），类型决定后续要抽取的内容结构资产（见适配表）。

**再填来源**（二选一）：

- **来源 A · 大 V 主页**：粘贴目标大 V 主页链接，拉取其发布内容
- **来源 B · 热门视频**：用户直接粘贴一条热门视频链接，作为复刻素材（不依赖账号主页）

**操作**：

1. 选类型 + 填来源（A 或 B）
2. 来源 A：设定时间范围（近 7 天 / 30 天 / 自定义）→ 拉取该账号发布内容 → 按数据维度排序（点赞量 / 转发量 / 评论量，默认按点赞量降序）
3. 来源 B：用户已粘贴单条热门视频链接，该视频即选定素材，跳过时间范围与排序
4. 运营确认要复刻的内容视频（来源 A 从排序结果中人工选定；来源 B 直接使用粘贴视频）

---

## 第二步：复刻生产（通用骨架）

1. 确定主体形象（★ 支持多类型数字人 / 角色，见下）
2. 确定配套要素：选定服饰 + 场景 + 视频风格
3. 1:1 还原参考视频，仅将出镜主体替换为自有数字人（详见适配表）：舞蹈类还原编舞动作 / 卡点节奏 / 镜头运镜，段子类还原选题 / 台词 / 包袱 / 表演节奏
4. 生成 AI 视频：套形象 + 服饰 + 场景 + 参考视频内容（含镜头信息）
5. 质检与包装：人工确认：崩坏修复 → 剪辑（BGM 用自有 / 授权）→ 字幕 / 花字 → 视频封面选取 → 合规审核（音乐 / 肖像 / 文案）

## 创意玩法（通用核心）

### 核心创意：一个爆款内容，多角色演绎

把同一个高赞内容，用不同类型的数字人重新演绎，让一条爆款长出多条内容线。用角色变化制造新鲜感，feed 内多套钩子（颜值 / IP 反差 / 萌宠）不重样。同一参考视频换不同数字人演绎，可产出多个变体；以数据表现择优。

### 三种演绎形态

- **真人风格数字人**：高颜值 / 有记忆点的 AI 形象
- **萌宠 / 萌物形象**：把内容「萌化」演绎，猫狗跳热舞 / 萌物吐槽，萌感 + 喜剧感双加成
- **角色团（IP 化）**：西游、封神、山海经怪兽等经典 IP 演绎现代热门内容，经典 × 热内容形成强反差，记忆点极强

### 落地支撑：内容平台要丰富资产体系

- **形象库**：多形态主体（真人风 / 萌宠 / IP 角色团）
- **服饰库**：与形象关联的多套服装
- **场景库**：实景 / 虚拟场景
- **内容结构库**：按品类存可复用结构资产——舞蹈存动作白模视频，段子存选题/钩子文案

## 创意拓展方向

1. **次元违和混搭**：把「不可能组合」放一起——唐僧孙悟空跳科目三、神仙演催婚、山海经怪兽演面试。违和感本身就是噱头，「次元壁破裂」比单纯换脸更有话题。
2. **节日 / 社会热点钩子**：春节催婚、情人节送礼、双十一剁手。让内容有「时间锚点」，蹭节日与社会情绪流量。
3. **互动 / Battle 机制**：角色团之间 Battle——唐僧队 vs 悟空队比谁的吐槽更好笑 / 谁的舞更齐；让用户投票选边、选结局、选下期主题。把内容变成用户可参与的互动玩法。
