# 热门舞蹈复刻 · 业务流程规范

> 基于抖音舞蹈大 V 内容，复刻为自有微信小程序分发的创意娱乐内容。
> 定位：靠数字人颜值吸引点击，封面直出数字人形象。

## 流程总览

| 阶段 | 目标 | 谁拍板 |
|---|---|---|
| 第一步 内容采集与选题 | 从大 V 主页筛出可复刻的舞蹈视频 | 运营人工选定 |
| 第二步 复刻生产 | 把选定视频复刻成自有数字人舞蹈内容 | 人工发布确认 |

## 第一步：内容采集与选题

**输入**：抖音舞蹈大 V 主页链接（美女单人 / 团体齐舞两类）

**操作**：
1. 粘贴主页链接，拉取该账号发布内容
2. 设定时间范围（如近 7 天 / 30 天 / 自定义）
3. 按数据维度排序：点赞量 / 转发量 / 评论量
4. 运营从排序结果中**人工选定**要复刻的舞蹈视频

**输出**：待复刻视频清单（含原视频动作 / BGM / 钩子信息）

> 设计要点：筛选只解决"哪些视频值得看"，最终复刻哪条由人定，不自动跑。

## 第二步：复刻生产

1. **确定主体形象**（★ 支持多类型数字人，见下）
2. **确定配套要素**：选定服饰 + 搭建 / 匹配场景
3. **提取动作资产**：从原视频抽取动作 / 卡点 / 镜头信息
4. **生成 AI 视频**：套形象 + 服饰场景 + 动作资产生成
5. **质检与包装**：崩坏修复 → 剪辑（BGM 用自有 / 授权）→ 封面直出数字人形象 → 合规审核（音乐 / 肖像 / 版权）→ 人工发布确认

## ★ 多类型数字人（核心设计）

一套复刻流程喂出多条内容线，主体形象支持三类：

| 类型 | 适用线 | 说明 |
|---|---|---|
| 真人风格数字人 | 美女类（潮流 / 国风） | 高颜值 AI 脸，封面直出，靠脸吸引点击 |
| 萌宠形象 | 萌宠跳舞线 | 热门舞蹈套到萌宠身上，二次复刻，打通 AI 萌宠内容 |
| 角色团 | 团舞类 | 面具匿名团 / 潮流少年团，不露脸、视觉冲击强 |

**形象库设计**（量产的命根子）：
- **形象库**：存多形态主体（真人风 / 萌宠 / 角色团），每条含 ID、风格标签、立绘 / 三视图、适用线
- **服饰库**：与形象关联的多套服装
- **场景库**：实景 / 虚拟场景
- **动作库**：从原视频提取的可复用动作资产

复刻时"从库选形象 + 配要素 + 套动作"，而非每条从零造人；同一套动作资产可被不同形象复用（一个热舞出真人版 / 萌宠版 / 角色团版）。

## 合规红线（发布前必过）

- **音乐**：发在自有小程序，抖音曲库授权不生效，只用商用授权音乐库或自有音频
- **肖像 / 形象**：用原创数字人 / 萌宠，不碰真人肖像
- **动作 / 视频**：避免直接搬运原视频，复刻的是动作结构而非画面
