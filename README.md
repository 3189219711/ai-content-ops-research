# AI 内容运营调研 / 对标拆解资料库

围绕「AI 内容运营」做的两类工作的归档：开源工具链调研，以及短视频 / 小红书对标账号的爆款拆解与复刻路径。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `AI内容运营工具链调研报告.html` | 6 个 AI 内容运营相关开源项目的对比调研（对比矩阵、技术栈、逐项详解） |
| `数字人健康科普_对标拆解报告.html` | 数字人健康科普方向的对标账号发现与拆解 |

| `benchmarks/` | 抖音对标账号的爆款拆解报告、复刻思路、分类汇总（Markdown） |
| `抖音账号/` | 拆解所依据的原始素材归档，按内容类目分组（主页信息、截图） |
| `assets/` | 报告引用的图片与结构化数据（封面图、账号数据 JSON） |
| `.workbuddy/memory/` | 工作日志，记录每次调研 / 拆解的过程、结论与踩过的坑 |

## benchmarks 内容说明

按内容类目分为几条线：

- AI 萌宠类：胖橘什么猫、拾宠不昧、打工小狗的日常、可爱胖橘的日常、Pearl，另有 `AI萌宠类-复刻路径汇总`
- 情感鸡汤类：若初情感、云朵电台
- 数字人跳舞类：芊芊baby，另有 `AI舞蹈动作迁移SOP与热门热舞复刻清单` 与复刻路径汇总
- 数字人唱歌类：实现方式拆解与版权规避方案
- 健康小贴士类：三类信息图样式拆解与复刻参考

每份账号报告的结构大致统一：账号数据 → 爆款识别 → 选题矩阵 → 爆款共性 → 可复用公式 → 人设定位 → 代表作深拆 → 最值得复用的几点。
