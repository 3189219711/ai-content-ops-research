# 每日运势图文 · 三类样式拆解与复刻参考

> 方向：玄学命理类视频下的「每日运势图文」
> 参考样图：3 张（可爱电子黄历 / 水墨传统黄历 / 12 生肖卡片）
> 目标：梳理可直接参考生成的版式、配色、信息模块，并扩展到生肖、星座、五行、MBTI 等主题。

---

## 一、三类样式总览

| 样式 | 核心风格 | 视觉记忆点 | 信息密度 | 适合主题 | 量产友好度 | 优先级 |
|------|---------|-----------|---------|---------|-----------|--------|
| **A. 可爱电子黄历** | 卡通古风、清新绿调、Q 版人物 | 古风女孩 IP + 四色生肖标签 + 宜忌清单 | 高 | 每日黄历、生肖运势、节气吉语 | 中 | 高 |
| **B. 水墨传统黄历** | 中式水墨、书法大字、山水背景 | 毛笔书法日柱 + 圆形生肖印章 + 水墨山水 | 中 | 甲子日/干支日、八字日运、传统文化 | 中 | 高 |
| **C. 12 生肖运势卡片** | 扁平插画、马卡龙色、网格卡片 | 12 宫格生肖头像 + 星级评分 + 短运势 | 中 | 12 生肖日运、周运、月运 | 高 | 高（最易量产） |

**共同规律**：三张图都在做同一件事——**把"今日运势"这种抽象信息，装进一个用户"愿意截图收藏"的图文模板里**。核心不是命理深度，而是**信息可视化 + 每日仪式感 + 可转发的吉利话**。

## 二、逐样式拆解

### 样式 A：可爱电子黄历

#### 2.1 版式结构（从上到下）

```
┌─────────────────────────────────────┐
│  [顶部标题栏] 2026年8月11日 星期二     │
│  [副标题] 农历六月廿九 丁巳日 电子黄历  │
│  [节气标签] 立秋·收日·天德黄道        │
├─────────────────────────────────────┤
│  [IP 形象] 古风女孩拿"收"字牌         │
├─────────────────────────────────────┤
│  一、当日旺衰生肖                      │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
│  │大吉 │ │次吉 │ │需谨慎│ │值日 │   │
│  │猴鸡牛│ │蛇兔马│ │猪 虎│ │ 蛇  │   │
│  └─────┘ └─────┘ └─────┘ └─────┘   │
│  [财神方位：正西]  [喜神方位：正南]     │
├─────────────────────────────────────┤
│  二、适合做什么（宜）                  │
│  [图标] 商务事务 / 人际相处 / 生活琐事 │
│  [⚠️ 收日提示]                        │
├─────────────────────────────────────┤
│  [穿搭旺运色]        [幸运数字]        │
│  首选：绿色/翠青色      3   8          │
│  少用：黑色/深灰                       │
├─────────────────────────────────────┤
│  [底部免责声明] 相信科学 仅供娱乐 理性观看│
└─────────────────────────────────────┘
```

#### 2.2 配色
- 主色：草本绿 / 米黄 / 暖白
- 辅色：红色（大吉）、橙色（次吉）、蓝色（需谨慎）、紫色（值日）
- 整体：低饱和、亲和、不迷信 scary

#### 2.3 核心元素
- **古风女孩 IP**：固定形象，建立账号辨识度。
- **四色生肖标签**：大吉 / 次吉 / 需谨慎 / 值日，一目了然。
- **宜忌清单 + 方位 + 幸运色/数字**：实用型玄学，用户觉得"照着做就行"。
- **免责声明**：必须加，规避封建迷信风险。

#### 2.4 复刻要点
- 固定 IP + 固定版式，只换日期、生肖、宜忌内容。
- 信息模块可扩展：把"生肖"换成"星座""MBTI""五行"，版式不变。
- 适合做成"电子黄历"系列化账号。

### 样式 B：水墨传统黄历

#### 2.1 版式结构（从上到下）

```
┌─────────────────────────────────────┐
│  [顶部] ·守一笔记·每日运势·           │
│  [日期] 8月18日·甲子日 [定日]印章     │
│  [大字书法] 甲子日                    │
│  [副标题] 定日宜定事，把方向先定下来   │
├─────────────────────────────────────┤
│  [三个圆形生肖印章]                   │
│   牛（最合）  猴龙（顺）  马（慎）     │
│   顺势而为   节奏顺畅    情绪起伏      │
│   利定方向   利推进沟通  少冲动变卦    │
├─────────────────────────────────────┤
│  [宜] 定计划/定方向/谈合作/做决策     │
│  [避] 反复横跳/临时变卦/冲动消费       │
├─────────────────────────────────────┤
│  ·今日吃穿建议·                       │
│  幸运色：黑蓝白   幸运方位：北方        │
│  幸运食物：黑豆 / 银耳 / 大米          │
├─────────────────────────────────────┤
│  [底部金句] 定好方向·稳步前行·好事自然来│
│  [右下角印章] 守一笔记                 │
└─────────────────────────────────────┘
```

#### 2.2 配色
- 主色：米白宣纸色、墨色、朱红印章色
- 辅色：靛蓝、金色描边
- 整体：传统、克制、有"文化感"

#### 2.3 核心元素
- **书法大字日柱**：视觉冲击强，传统玄学味浓。
- **圆形生肖印章**：把"今日最合/顺/慎"做成印章样式，文化符号明确。
- **宜/避二分**：信息直接，用户"该做什么不该做什么"很清楚。
- **吃穿建议**：把玄学落到日常生活，增强实用性。

#### 2.4 复刻要点
- 版式更像"传统文化海报"，适合走"干支日""甲子日""节气"等知识向。
- 可以结合八字日柱、六十甲子、二十四节气做系列。
- 背书感强，适合塑造"懂传统文化"的人设。

### 样式 C：12 生肖运势卡片

#### 2.1 版式结构

```
┌─────────────────────────────────────┐
│  [大标题] 12生肖今日运势              │
│  [日期] 8月12日 星期三               │
├─────────────────────────────────────┤
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐       │
│  │ 鼠 │ │ 牛 │ │ 虎 │ │ 兔 │ ...   │
│  │头像│ │头像│ │头像│ │头像│        │
│  │短运│ │短运│ │短运│ │短运│        │
│  │★★★│ │★★★│ │★★★│ │★★☆│        │
│  └────┘ └────┘ └────┘ └────┘       │
│  （3×4 共 12 张卡片）                 │
├─────────────────────────────────────┤
│  [底部] 保持积极心态，好运自然来！     │
└─────────────────────────────────────┘
```

#### 2.2 配色
- 主色：马卡龙浅色底（淡蓝、淡粉、淡黄、淡绿）
- 辅色：金色/橙色用于星级和标题
- 整体：轻快、可爱、无压迫感

#### 2.3 核心元素
- **12 宫格卡片**：信息平均分配，每个生肖都有专属空间。
- **可爱动物头像**：扁平插画风格，降低玄学距离感。
- **星级评分**：把运势量化成 1–5 星，用户一眼看懂。
- **短运势文案**：30 字以内，含建议动作。

#### 2.4 复刻要点
- 这是**量产友好度最高**的版式——模板固定，每天只换日期和 12 条短文案。
- 最容易扩展到星座（12 星座）、MBTI（16 型，可改成 4×4）、五行等主题。
- 评论区天然有互动点："我属 X，今天几星？"

## 三、共同信息模块（三类通用）

无论走哪种风格，每日运势图文都包含以下 6 类信息模块：

| 模块 | 作用 | 用户价值 |
|------|------|---------|
| **日期/农历/干支** | 建立"今日专属"仪式感 | 觉得"这是今天的" |
| **生肖/星座/MBTI 运势** | 让用户对号入座 | 找到"自己那条" |
| **宜/避/吉凶标签** | 给出行动指引 | 照着做有心理安慰 |
| **幸运色/方位/数字/食物** | 实用玄学落地 | 可以截图保存 |
| **吉语/金句** | 情绪收尾 | 转发理由 |
| **免责声明** | 合规保命 | 规避封建迷信风险 |

**复刻公式**：
> 固定版式 + 日期模块 + 运势模块（生肖/星座/MBTI/五行） + 宜避/幸运建议 + 吉语 + 免责声明

## 四、主题扩展：生肖 → 星座 → 五行 → MBTI

你的思路很对：**版式是一套，主题可以无限换**。下面是替换矩阵：

| 主题 | 适配样式 | 内容产出方式 | 用户互动点 |
|------|---------|------------|-----------|
| **生肖** | A / B / C | 每日生肖吉凶、宜避 | "我属 X，今天怎么样？" |
| **星座** | C 最佳 | 12 星座日运/周运/月运 | "XX 座集合" |
| **五行** | B 最佳 | 每日五行穿衣/食物/方位 | "今天五行属 X，穿 X 色" |
| **MBTI** | C 最佳（16 张 4×4） | 16 型人格今日运势 | "INTJ 今天几星？" |
| **塔罗** | A / B | 每日一张牌 + 运势解读 | "抽到了 X 牌" |
| **二十四节气** | B 最佳 | 节气养生/开运指南 | "今日 X 节气" |
| **老黄历宜忌** | A / B | 每日宜做/不宜做 | "今天宜 X，忌 X" |

**建议**：
- **先用生肖跑通 C 样式**（12 宫格，最简单）。
- 跑通后，同一账号可以穿插「星座日运」「MBTI 日运」「五行穿衣」等内容，**版式不变，只换主题**。
- 不要把所有主题混在一张图里；一张图只服务一个主题，保持信息清晰。

## 五、复刻 SOP

1. **定主视觉风格**：三选一（可爱电子黄历 / 水墨传统 / 12 宫格卡片）。
2. **设计固定模板**：在 Canva / 稿定设计 / 创客贴 / PS / Figma 里做好版式，导出为可替换模板。
3. **建立素材库**：
   - 生肖/星座/MBTI 图标（统一风格）
   - 古风女孩 IP（如选 A）
   - 水墨山水背景（如选 B）
   - 颜色/字体/印章元素
4. **准备运势文案库**：
   - 12 生肖每日短运势 × 3 套（不同风格）
   - 宜/避文案模板
   - 幸运色/方位/数字/食物库
5. **每日生产流程**：
   - 查当日农历/干支/节气
   - 选对应生肖/星座运势文案
   - 填进模板，导出 9:16 竖图或 1:1 方图
   - 加音乐做成短视频，或发图文
6. **发布 + 互动引导**：
   - 文案："你属什么/什么星座/MBTI 是什么？评论区看看今天几星"
   - 引导截图保存、转发给闺蜜
7. **加免责声明**：每条都必须有「相信科学 仅供娱乐 理性观看」或类似表述。

## 七、避坑清单

1. **必须加免责声明**：每条图文/视频都要加「相信科学 仅供娱乐 理性观看」，规避封建迷信风险。
2. **不要做具体个人预测**：只说"群体运势"，不要点名某个人或引导付费算命。
3. **不要涉及疾病、投资、法律决策**：比如"今天宜做手术""今天宜买股票"这种高风险建议绝对不要出现。
4. **不要恐吓式文案**：避免"今日大凶""必破财"等制造焦虑的表述。
5. **统一视觉风格**：一个账号不要今天可爱明天水墨，风格混乱会削弱信任感。
6. **图标素材要原创或授权**：生肖/星座图标不要直接搬运网图，建议用 AI 生成统一风格。
7. **数据要 Daily 更新**：既然是"每日运势"，日更是基本要求；断更会伤账号权重。
8. **互动引导要具体**："评论区留下你的生肖"比"大家觉得准吗"互动率高得多。

## 八、起步优先级

| 优先级 | 样式 | 理由 |
|--------|------|------|
| **第一** | **C. 12 生肖运势卡片** | 模板最固定、量产成本最低、评论区互动点天然强 |
| **第二** | **A. 可爱电子黄历** | 信息密度高、收藏欲强、IP 形象可形成账号记忆点 |
| **第三** | **B. 水墨传统黄历** | 文化质感强、适合走"传统文化+运势"差异化，但制作门槛稍高 |

**起步建议**：
1. 先做 **C 样式 12 生肖日运**，跑通每日生产流程。
2. 同时设计一个固定 IP/固定色调，为 A 样式做准备。
3. 等日更稳定后，每周穿插 1 条 B 样式（水墨干支日/节气），拉高账号质感。
4. 所有主题（生肖/星座/MBTI/五行）共用同一套视觉资产库。

## 九、一句话结论

**每日运势图文的复刻本质 = 一套固定图文模板 + 每日可替换的运势信息 + 强烈的"对号入座"互动设计。它不是命理深度竞争，而是"谁的信息更清晰、更好截图保存、更有转发吉利话"。建议先用 12 宫格生肖卡片跑通日更，再叠加可爱电子黄历和水墨黄历提升质感，并把主题扩展到星座、MBTI、五行等，形成"同一模板、多主题轮播"的账号矩阵。**
