# 健康小贴士类：三类样式拆解与复刻参考

> 目标：把参考图的风格/版式/结构拆成可直接执行的样式模板，用于后续批量复刻。

---

## 一、三类样式总览

| 样式 | 视觉关键词 | 核心版式 | 适合主题 | 制作难度 | 量产友好度 |
|------|-----------|---------|---------|---------|-----------|
| A. 3D 轻拟物信息图 | 3D 图标、立体字、左右对比、糖果色 | 大标题 + 双栏对比（红榜/黑榜、能/不能） | 食物红黑榜、成分对比、饮食建议 | 中 | 高 |
| B. 健康计划信息图 | 清新配色、表格/卡片、序号流程、生活场景插画 | 时间轴 / 一周计划 / 步骤清单 | 一周食谱、每日习惯、节气养生 | 低 | 极高 |
| C. 手绘扁平插画信息图 | 水彩纸纹理、手绘食物/人物、自然绿色调、文艺感 | 多宫格 / 分类卡片 / 图文解说 | 时令养生、食材功效、食疗科普 | 中 | 中 |

## 二、样式 A：3D 轻拟物信息图

### 2.1 代表作品
- 《控糖饮食 · 主食篇》
- 《控糖饮食 · 水果篇》

### 2.2 视觉公式
- **背景**：高饱和度纯色底（橙/蓝），营造冲击力。
- **标题**：3D 立体膨胀字 + 浅色描边阴影，副标题用深色条带衬托。
- **主体**：左右双栏卡片，分别代表「推荐 / 不推荐」「控糖 / 升糖」「能吃 / 少吃」。
- **图标**：3D 轻拟物食物模型，带光泽和阴影，放在圆角卡片里。
- **标签**：顶部一句话总结类别（如"全谷物、杂豆类、薯类、高纤维"）。
- **装饰**：对勾、星星、卡通小元素点缀。

### 2.3 版式结构
```
[主标题 3D 大字]
    [副标题/篇名]

┌───────────────┐  ┌───────────────┐
│   [左栏标签]   │  │   [右栏标签]   │
│  左栏说明文字  │  │  右栏说明文字  │
│               │  │               │
│  [图标] 名称   │  │  [图标] 名称   │
│  [图标] 名称   │  │  [图标] 名称   │
│  [图标] 名称   │  │  [图标] 名称   │
│     ...       │  │     ...       │
└───────────────┘  └───────────────┘
```

### 2.4 可替换元素
| 元素 | 示例 | 可换成 |
|------|------|--------|
| 主题 | 控糖饮食 | 减脂饮食、降压饮食、养胃饮食、抗炎饮食 |
| 分类维度 | 控糖 / 升糖 | 高蛋白 / 高脂肪、护眼 / 伤眼、助眠 / 失眠 |
| 图标 | 主食/水果 | 零食、饮品、调味品、运动类型 |
| 配色 | 橙+蓝 | 绿+红、紫+黄，按情绪定 |

### 2.5 复刻要点
1. 先用 MJ/即梦生成一套统一的 3D 食物/物品图标（固定角度、固定光影）。
2. 背景色和卡片色必须拉开对比，左右两栏冷暖分明。
3. 标题字要做厚 + 投影，是第一眼留人的关键。
4. 每栏 6–8 个 item 为佳，不要太密。

## 三、样式 B：健康计划信息图

### 3.1 代表作品
- 《控糖饮食计划 · AI 定制控糖餐》
- 《8 月养生指南》
- 《从今天开始拥抱健康生活》

### 3.2 三个子版式

#### 子版式 B1：一周计划表
- **结构**：周一到周日，每天一行，早/午/晚三餐横向排列，加号连接。
- **视觉**：浅绿背景 + 绿色圆角标签（周 X 饮食）+ 食物插画 + 黑色加号。
- **适合**：一周食谱、一周运动计划、一周作息表。

#### 子版式 B2：数字步骤卡片
- **结构**：1/2/3/4/5/6 编号卡片，每个卡片有图标、标题、"为什么重要"、"小技巧"。
- **视觉**：每张卡片一个主题色，配小插画（人物动作/场景）。
- **适合**：每日健康习惯、养生步骤、护眼/护腰指南。

#### 子版式 B3：编号长文列表
- **结构**：标题 + 一段解释文案，4–6 条竖排。
- **视觉**：暖色渐变标题 + 浅棕/米白卡片 + 手写感装饰花。
- **适合**：鸡汤感健康建议、节气养生、情绪管理。

### 3.3 版式结构（以 B1 为例）
```
[主标题]
[副标题]

┌────┐   ┌────┐   +   ┌────┐   +   ┌────┐
│周一 │   │早餐│       │午餐│       │晚餐│
│饮食 │   │图标│       │图标│       │图标│
└────┘   └────┘       └────┘       └────┘

[周二 ... 周日重复]
```

### 3.4 可替换元素
| 元素 | 示例 | 可换成 |
|------|------|--------|
| 时间维度 | 一周七天 | 一天四时段、一个月四周、一年四季 |
| 内容维度 | 饮食 | 运动、睡眠、喝水、护眼、护腰 |
| 编号主题 | 养生指南 | 秋季养生、春节后减脂、熬夜修复 |
| 插画风格 | 清新扁平人物 | 卡通小动物、简笔画小人 |

### 3.5 复刻要点
1. B1 计划表：保持每天版式完全一致，只换内容，系列感最强。
2. B2 步骤卡：每步配一个小场景插画，"为什么重要"用短句，"小技巧"要具体可执行。
3. B3 长文列表：标题要有情绪感染力（"从今天开始拥抱..."），正文口语化、带emoji/小图标。
4. 三类子版式可互相组合：比如先做 B1 的一周计划，再拆成 7 条 B2 每日小贴士。

## 四、样式 C：手绘扁平插画信息图

### 4.1 代表作品
- 《秋天养皮肤的九种食物》
- 《补水润燥类 · 对付干燥》
- 《抗氧化组 · 让皮fu亮起来》
- 《让皮肤更强健 & 综合调理》

### 4.2 视觉公式
- **背景**：模拟水彩纸/素描纸纹理，浅色底，文艺自然感。
- **标题**：手写感圆润字体，绿色为主，可配英文副标题。
- **主体**：
  - 总览图：九宫格 / 六宫格，每个格子一个手绘食物 + 名称。
  - 详解图：每个食物一张卡片，左图右文或左文右图，配功效说明。
- **插画**：扁平水彩风格食物，边缘柔和，颜色明亮但不刺眼。
- **排版**：大量留白，卡片间距大，阅读节奏舒缓。

### 4.3 版式结构
```
[手写感主标题]
[英文副标题 / 小标题]

┌─────┐  ┌─────┐  ┌─────┐
│ 图  │  │ 图  │  │ 图  │
│ 名称 │  │ 名称 │  │ 名称 │
└─────┘  └─────┘  └─────┘
┌─────┐  ┌─────┐  ┌─────┐
│ 图  │  │ 图  │  │ 图  │
│ 名称 │  │ 名称 │  │ 名称 │
└─────┘  └─────┘  └─────┘

--- 分隔 ---

┌─────────────────────────┐
│  [食物插画]   [名称]      │
│             [功效说明]   │
└─────────────────────────┘
[下一张卡片...]
```

### 4.4 可替换元素
| 元素 | 示例 | 可换成 |
|------|------|--------|
| 主题 | 秋天养皮肤 | 春天养肝、夏天祛湿、冬天补肾、熬夜修复 |
| 数量 | 九种食物 | 五种、七种、十种，按内容灵活调整 |
| 食物类型 | 水果/蔬菜/汤饮 | 茶饮、穴位、运动、习惯 |
| 文案风格 | 功效说明 + 比喻 | "肠道清道夫""抗氧化之王""让皮fu亮起来" |

### 4.5 复刻要点
1. 插画必须统一手绘风格，不能一张写实、一张 3D，会破坏系列感。
2. 标题文案要软萌/接地气，适当用拼音替代字（如"皮fu"）降低说教感。
3. 总览图负责"收藏"，详解图负责"转发/学习"；可以一鱼两吃。
4. 水彩纸纹理是氛围关键，找不到合适的底纹宁可纯色也别用廉价纹理。

## 五、三类样式的选题适配矩阵

| 选题方向 | 推荐样式 | 理由 |
|---------|---------|------|
| 食物红黑榜 | A | 对比冲击强，第一眼就懂 |
| 一周食谱/计划 | B1 | 结构清晰，系列化最简单 |
| 每日健康习惯 | B2 | 步骤感强，易收藏转发 |
| 节气/时令养生 | C | 文艺感强，符合养生调性 |
| 食材功效科普 | C | 插画+详解，信息密度适中 |
| 情绪/生活方式 | B3 | 文案可情绪化，共鸣感强 |
| 营养成分对比 | A | 对比视觉最直接 |

## 六、三类样式的通用复刻公式

**复刻公式 = 固定版式壳 + 替换主题/食材/文案 + 统一视觉资产**

1. **先选定一个版式壳**（A/B1/B2/B3/C），把它做成模板。
2. **建立视觉资产库**：
   - A：一套 3D 图标（20–30 个常用食物/物品）。
   - B：一套人物/场景小插画、一套数字标签样式。
   - C：一套手绘食物/植物插画、一套水彩纸纹理。
3. **内容模块化**：标题公式、副标题公式、item 文案公式固定下来，只换关键词。
4. **批量生成**：同一模板连续出 5–10 条不同主题，快速测试哪类数据最好。
5. **系列化命名**：加"第 X 期""XX 篇"，降低用户追更成本。

## 七、优先级建议

| 优先级 | 样式 | 理由 |
|-------|------|------|
| 高 | B1 一周计划表 | 制作门槛最低，模板化程度最高，可日更 |
| 高 | A 3D 对比信息图 | 视觉冲击强，完播率和收藏率高 |
| 中 | B2 数字步骤卡片 | 适合系列化，但插画成本稍高 |
| 中 | C 手绘插画信息图 | 调性好，但插画统一性和量产难度较大 |
| 低 | B3 长文鸡汤列表 | 容易同质化，需要强文案才能跑出来 |

---

## 八、避坑清单

1. **同一账号内风格不要跳**：3D、清新、手绘三类不要混着发，会稀释账号视觉记忆。
2. **图标/插画必须统一光源和角度**：否则看起来像素材拼凑。
3. **文字不要堆满**：健康小贴士是"看图就够"，字多就输了。
4. **配色不要超过 4 种主色**：A 类虽然饱和度高，但也是 2 主色 + 1 点缀。
5. **不要直接搬运参考图的字体和排版元素**：提取结构即可，具体字体/装饰要换。

---

## 九、一句话结论

**健康小贴士类的爆款壳不是"画得多好看"，而是"一眼能收藏、一图能转发"——A 类用对比降低决策成本，B 类用计划降低执行成本，C 类用文艺感降低说教感。先定一个主风格跑通模板，再用同一视觉资产库批量换主题，是最稳的复刻路径。**
