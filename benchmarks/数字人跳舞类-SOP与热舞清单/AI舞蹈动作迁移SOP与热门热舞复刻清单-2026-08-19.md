# 数字人跳舞类：AI 舞蹈动作迁移 SOP 与热门热舞复刻清单

> 说明：本文档聚焦「AI 动作迁移/舞蹈复刻」方向——用参考视频锁死动作和运镜，再替换成自己的角色与场景。与芊芊 baby 式"固定数字人美女 + 每日换装 + 简单手势舞"的带货逻辑不同，本方向更偏娱乐传播，核心指标是转发率与完播率。

---

## 一、核心制作流程 SOP（5 个关键步骤）

来源：视频教程文案提炼，把实操压缩为 5 个关键节点，每个节点内部细节可再展开。

| 步骤 | 关键动作 | 关键注意 |
|------|---------|---------|
| 1 | **选取并预处理参考视频** | 选近 30 天爆款热舞；用剪辑软件按 **≤15s** 切段；用人物特效遮挡原人脸，避免生成带脸被判搬运。 |
| 2 | **生成绿幕白模动作视频** | 参考视频上传 AI 画布（**16:9**，时长对齐），输入白模提示词，得到无脸素体动作参考。 |
| 3 | **准备替换素材** | ①角色三视图（锁定主角形象一致性）；②场景图（锁定背景）。 |
| 4 | **合并生成最终片段** | 把「白模视频 + 角色图 + 场景图」三合一，输入合并提示词，注意 **@** 准确对应各素材；多段重复此步。 |
| 5 | **剪辑拼接 + 配乐** | 多段片段拼接，重新配 BGM，出成品。 |

### 流程图意

```
参考视频（分段+遮脸）→ 生成绿幕白模动作视频
                              ↓
白模视频 + 角色三视图 + 场景图 → 合并提示词 → 替换后片段
                              ↓
多段片段 → 剪辑拼接 → 重新配乐 → 成品
```

## 二、两个关键提示词模板

### 提示词 A：制作绿幕白模舞蹈动作参考视频

```
以上传参考视频为唯一基准 1:1 复刻全部舞蹈内容。
全部角色采用 3D 基础红白素体，无脸无五官无头发无服饰无纹理无真实皮肤，
仅保留简洁人形结构与清晰关节，中央主角为红色素体，其余配角为白色素体；
红色素体完全复刻原视频中央主角的全部舞蹈动作，精准匹配脚步、抬手、摆臂、
躯干倾斜、弹跳、重心变化、转向、停顿与定格姿势，
所有白色素体配角严格对应原视频人物，复刻其动作、站位、前后层次、左右分布、
移动轨迹与节奏；所有动作的起始时间、落点、强拍定格、节奏变化均与原视频帧级对齐，
镜头运镜与画面构图完全复刻原视频，背景是绿幕，不新增任何额外元素。
```

**用途**：把真人/任意参考视频的动作、节奏、运镜抽象成无版权争议的素体动作库。

### 提示词 B：合并视频与图片，生成最终角色替换视频

```
参考 @视频 的运镜、景别、镜头节奏、音乐卡点和舞蹈编排，
使用 @图1 作为 C 位男主，保持人物外貌、发型、身材和气质高度一致，
高度还原原视频中男主的全部舞蹈动作与节奏；
周边所有伴舞替换成 @图2，场景参考 @场景图，
两侧同步匹配原视频伴舞的动作、站位和队形变化，角色动作严格按照视频里的。
写实真人质感，好莱坞动作音乐大电影，
融合好莱坞歌舞动作大片的镜头语言，动作丝滑流畅，运镜稳定顺滑，节奏精准卡点。
```

**注意**：提示词里 `@视频`、`@图1`、`@图2`、`@场景图` 要一一对应上传的素材。

## 四、可复刻的变量替换公式

核心原则：**动作和运镜照抄参考视频，角色、场景、风格全部换成自己的**。

| 固定元素（必须对齐参考视频） | 可变元素（必须替换，避免搬运） |
|---------------------------|---------------------------|
| 舞蹈动作轨迹 | 主角形象（真人/萌宠/影视角色/原创角色） |
| 节奏与强拍定格 | 伴舞形象与数量 |
| 镜头运镜与景别 | 场景（古墓/天宫/街头/草原/麻辣烫店） |
| 队形与站位 | 视觉风格（写实/卡通/3D CG/国风） |
| 视频时长与分段点 | BGM 与歌词字幕 |

### 推荐变量组合

| 组合编号 | 主角 | 伴舞 | 场景 | 风格 | 适合热舞 |
|---------|------|------|------|------|---------|
| 1 | 原创萌宠（猫/狗） | 同类萌宠群 | 街头/美食店 | 可爱写实 | 加麻不加辣、正太扭腰 |
| 2 | 经典影视角色（唐僧/悟空/八戒） | 同剧角色 | 天宫/古墓/雪山 | 电影级写实 | 三人拖拉机、满级病友 |
| 3 | 原创虚拟偶像 | 木乃伊/怪兽群 | 埃及古墓/废墟 | 3D CG | jumpstyle |
| 4 | 萌宠 + 歌词字幕 | 无伴舞 | 纯色/简单场景 | 萌系 | 梦的翅膀 DJ |

## 五、执行优先级建议

1. **先跑通 SOP**：用「正太扭腰舞」或「加麻不加辣」这类动作简单、角色可爱的试水，验证白模 → 合并 → 剪辑整条链路。
2. **再追高热梗**：「梦的翅膀受了伤 DJ」已有爆款验证，优先做角色替换（如换成你自己的萌宠或虚拟形象）。
3. **最后做视觉冲击**：「jumpstyle」和「三人拖拉机」对场景和角色一致性要求高，作为 occasional 大片。

## 六、避坑清单

| 坑 | 后果 | 规避方法 |
|---|------|---------|
| 参考视频带脸未遮挡 | AI 生成时把原人物脸带进去，被判搬运 | 步骤 3 务必面部遮挡 |
| 单段超过 15 秒 | AI 生成失败率高、动作漂移 | 严格按 15 秒分段 |
| 提示词里 @ 对应错 | 角色/场景错位 | 上传素材后核对节点编号 |
| 角色形象不固定 | 账号没有记忆点 | 同一系列用同一套角色三视图 |
| 直接搬运原视频 BGM+画面 | 平台判重/下架 | 必须换角色、换场景、换风格 |
| 只追复杂舞蹈忽视传播点 | 数据跑不赢 | 优先选"有梗""有反差""有转发欲"的热舞 |

---

## 七、一句话结论

**AI 舞蹈动作迁移的复刻公式 = 爆款参考视频（锁动作/运镜/节奏）+ 自己的角色/场景/风格（换皮）+ 抖音热梗/BGM（蹭流量）**。先把 SOP 跑通，再用萌宠/经典角色快速验证，最后堆视觉复杂度。
