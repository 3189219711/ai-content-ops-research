## 三、核心爆款公式

**若初情感公式 = 温柔治愈女声 + 舒缓氛围音乐 + 夜景行人/背影素材 + 固定版式大字文案 + 情绪共鸣选题**

| 层级 | 具体表现 | 作用 |

| **声音层** | 温柔、低语速、略带沙哑的女声；像深夜电台主播 | 建立陪伴感和信任感 |
| **音乐层** | 舒缓钢琴/吉他/氛围音乐，音量低于人声 | 放大情绪，不抢戏 |

| **选题层** | 人生低谷、爱情遗憾、自我疗愈、珍惜当下 | 击中深夜情绪脆弱的受众 |

## 四、视觉版式拆解

### 4.1 画面构图
- **主体**：人物背影或侧影，处于画面中下方，占比约 1/3。
- **背景**：城市夜景，行人、街道、车辆虚化处理，强调孤独感和氛围感。
- **色调**：暗调，以蓝、橙、黑为主，低饱和，电影感。
- **运镜**：几乎无运镜，固定机位或极轻微慢推，保持"旁观"感。

### 4.2 文字层级（从上到下）

```
┌─────────────────────────────────────┐
│  [右上角小字：好好爱自己 / 时间会治愈一切]  │
│                                     │
│  [主标题大字：在我最难的时候]           │
│  [主标题大字：谁也没有让我变好]          │
│                                     │
│  [英文小字：RUOCHU EMOTIONS]          │
│                                     │
│        [人物背影 / 夜景街道]          │
│                                     │
│  [中部字幕：我们绝大多数人......]        │
│                                     │
│  [右下角圆形头像：若初]                │
└─────────────────────────────────────┘
```

### 4.3 字体与动效
- 主标题：白色粗体/书法感字体，带轻微阴影，静态或缓慢浮现。
- 英文小字：衬线体，居中对齐，增加文艺感。
- 中部字幕：较小字号，配合口播逐句出现，引导完播。
- 右上角小字：情绪金句，强化主题。

## 五、文案结构模板

爆款文案基本遵循 **"痛点共鸣 → 情绪放大 → 温柔结论"** 三段式：

### 5.1 主标题公式
| 类型 | 公式 | 案例 |
|------|------|------|
| 低谷自白 | 在我/当我们 + 最 X 的时候，谁也没有 + 动词 + 我 | 在我最难的时候，谁也没有让我变好 |
| 关系顿悟 | 当/如果 + 负面行为 + 以后，就再也没有 + 美好事物 | 恶语相向以后，就再也没有爱了 |
| 人生哲理 | 世间/人生 + 宏大判断，珍惜/放下/接纳 + 就是 + 圆满/解脱 | 世间万物终究皆空，珍惜当下就是圆满 |

### 5.2 口播文案公式
1. **钩子**（前 3 秒）：重复或扩展主标题，建立共鸣。
2. **场景描写**："你是不是也这样过......" / "我们绝大多数人......"
3. **情绪展开**：讲一个普遍但私密的感受。
4. **温柔结论**：给出不尖锐、不爹味的安慰或觉醒。

### 5.3 爆款选题方向
| 方向 | 案例 | 情绪点 |
|------|------|--------|
| 自我疗愈 | 在我最难的时候，谁也没有让我变好 | 孤独后的自我接纳 |
| 关系遗憾 | 恶语相向以后，就再也没有爱了 | 爱情里的不可逆伤害 |
| 人生释怀 | 世间万物终究皆空，珍惜当下就是圆满 | 放下执念 |
| 人间清醒 | （合集标签） | 看破但不点破 |
| 情感治愈 | （合集标签） | 被理解、被接住 |

## 六、声音与音乐

### 6.1 声音特征
- **音色**：温柔女声，语速慢，咬字轻，尾音带轻微叹息感。
- **情绪**：不激动、不说教，像朋友深夜聊天。
- **技术实现**：真人配音 或 高品质情感类 TTS（如剪映"温柔女声"、魔音工坊、微软晓晓等）。

### 6.2 音乐特征
- **类型**：轻音乐、钢琴、吉他、氛围电子。
- **情绪**：舒缓、略带忧伤但不沉重。
- **作用**：铺垫情绪，让受众"慢下来"听完。
- **来源**：抖音音频库、剪映自带 BGM、可商用轻音乐库。

## 七、背景视频来源与制作

### 7.1 背景视频类型
- 城市夜景行人（背影/侧影）
- 雨天街道、撑伞行人
- 路灯/车灯虚化、人来人往
- 固定机位或极轻微慢镜头

### 7.2 可能来源
| 来源 | 说明 |
|------|------|
| 素材网站 | Pexels / Pixabay / Mixkit 搜索 "night city people walking" |
| 抖音拍同款 | 主页写"可点音频直接拍同款"，说明有开放音频/模板 |
| 自己拍摄 | 夜晚手机街拍，注意人物不露脸 |
| AI 生成 | 可灵 / 即梦生成 "夜晚城市街道，行人背影，电影感，虚化灯光" |

### 7.3 制作注意
- **人物不要露脸**：背影/侧影/虚化，降低肖像权风险。
- **保持暗调**：避免白天明亮素材，破坏氛围。
- **要有"流动感"**：背景必须有行人或车流，但不能太抢眼。

## 九、复刻 SOP

1. **定人设**：情感治愈向，名字 2–3 字 + "情感/夜话/治愈/心事"。
2. **建模板**：在剪映/PR 里做好固定版式（主标题位置、英文小字位置、中部字幕位置、头像位置）。
3. **备素材**：批量收集 20–30 条夜晚城市行人/背影/氛围素材，统一暗调。
4. **写文案**：按"痛点共鸣 → 情绪放大 → 温柔结论"写 30 秒口播文案。
5. **配音**：用温柔女声 TTS 或真人录制，语速放慢。
6. **加字幕**：
   - 主标题：2 行大字，前 3 秒出现。
   - 中部字幕：随口播逐句出现。
   - 右上角：一句情绪金句。
7. **配音乐**：舒缓钢琴/吉他，音量压到 20%–30%。
8. **调色**：压暗、降饱和、加轻微电影感 LUT。
9. **输出**：竖屏 9:16，1080×1920。
10. **测选题**：优先测"低谷自白""关系遗憾""人生释怀"三类，再扩展。

## 十、为什么低量视频跑输

| 低量视频 | 问题 |
|---------|------|
| 一定要多夸夸自己 | 选题正向但无痛点，缺乏情绪钩子 |
| 千人追不如一人疼 | 话题老套，文案没有具体场景 |
| 你是我动了情却不属于我的人 | 情感话题但表述常见，未触发"被理解"感 |

**共同问题**：
1. 文案太泛，没有具体画面感。
2. 情绪太平，没有"痛一下再被接住"的起伏。
3. 缺少"这就是我"的代入点。

---

## 十一、避坑清单

1. **不要露脸**：情感类账号背影/侧影更安全，也更有"任何人都能代入"的感觉。
2. **不要大声说教**：温柔陪伴感是核心，爹味文案一秒划走。
3. **音乐不要抢戏**：人声必须清晰，BGM 只是情绪底色。
4. **画面不要太复杂**：背景只能烘托，不能分散注意力。
5. **不要直接搬运原视频文案**：提取结构后重写，避免被判定搬运。
6. **同一账号视觉要统一**：主标题位置、字体、色调、音乐风格必须固定。

---

## 十二、最值得抄的 3 点

1. **固定视觉模板 + 可变文案**：背景、字体、音乐、头像位置全部固定，只换文案和素材，日产 3–5 条成本极低。
2. **"深夜陪伴"人设**：不是讲道理，而是替用户把心里话说出来，收藏率和转发率极高。
3. **大字主标题做钩子**：前 3 秒标题必须让用户觉得"在说我自己"，这是完播率的关键。
