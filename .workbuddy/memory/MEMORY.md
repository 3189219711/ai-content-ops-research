# AI内容运营开源项目调研 · 长期项目笔记

## 抖音账号单拆模板（定稿）

- 产物目录：`账号单拆/<账号名>.md`
- 适用场景：把抖音爆款娱乐账号拆解后，换皮复刻成自己的娱乐账号（非健康号），视频最终发在自有微信小程序。
- 结构（2 模块，单账号文件）：
  1. 账号特点与爆款公式：账号基础信息行 + 定位 + 一句话乘法公式。
  2. 爆款内容清单：每条代表作配一张截图（来源 `抖音账号/.../<账号名>/`），列出数据/BGM/判断；保留反面案例。
- 注意：「我们复刻可以怎么做的」板块**和**「侵权风险」板块都**不在单账号文件里**，待萌宠类多个账号梳理完后统一合并补充（跨账号汇总）。单账号文件只做拆解，不做复刻/合规建议。
- 音乐红线硬约束（第四节必须写）：视频发在自有微信小程序，抖音/视频号/汽水音乐等曲库授权不生效；音频只能用「商用授权音乐库」或「自有音频（翻唱/AI 生成/原创）」。
- 截图引用规则：使用相对路径 `../抖音账号/<分类>/<账号名>/<文件名>.jpg`，Markdown 图片语法内嵌。
