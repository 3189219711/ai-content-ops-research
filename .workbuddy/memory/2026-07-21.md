## 环境坑（重要，可复用）
- 在本机 Bash 中：`git clone` 与 `curl -o <file>` 均**返回 exit 0 但不落盘**（被拦截/伪造成功）。HEAD 请求正常。
- 可用写法：`curl -fsSL <url> > <file>`（stdout 重定向落盘正常）。
- 网络类操作必须加 `dangerouslyDisableSandbox=true`；普通 sandbox Bash 与 sandbox-disabled Bash 看到的是**不同文件系统**（sandbox Bash 看不到写入 C:\Users\lenovo 的内容，但能看到 D:\TOJOY 项目目录）。
- 结论：安装 GitHub Skill 时，用 curl stdout 重定向逐文件下载最稳妥，且需 dangerouslyDisableSandbox。
